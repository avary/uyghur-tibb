# ئۇيغۇر تېبابىتى تەلىم-تەربىيە سۇپىسى (Uyghur Tibb Platform)

مەزكۇر تۈر ئۇيغۇر تېبابىتى دەرسلىكلىرى، سىناق ئىمتىھانلىرى، ئوقۇغۇچى باشقۇرۇش سىستېمىسى ۋە سۇئال-جاۋاب مۇنبىرىنى ئۆز ئىچىگە ئالغان زامانىۋى تور ئەپ (PWA) ۋە تەلىم-تەربىيە سۇپىسىدۇر.

---

## 🌟 ئاساسلىق ئىقتىدارلىرى (Features)
- 📱 **بىر كۇنۇپكا بىلەن تېلېفونغا قاچىلاش (PWA):** تېلېفون ۋە كومپيۇتېردا تولۇق ئەپ سۈپىتىدە ئىشلەيدۇ.
- 📚 **دەرسلىك ۋە كىتاب باشقۇرۇش:** بارلىق دەرسلەر (1-دىن 10-غىچە ۋە ئۇنىڭدىن كۆپ)، PDF دەرسلىكلەرنى يۈكلەش، ئىسمىنى ئاپتوماتىك تونۇش ۋە باشقۇرۇش.
- 👨‍🎓 **ئوقۇغۇچى تەستىق تۈزۈمى (Gatekeeper):** يېڭى تىزىملاتقان ئوقۇغۇچىلار باشقۇرغۇچى تەرىپىدىن تەستىقلانغاندىن كېيىن ئاندىن دەرسكە كىرەلەيدۇ.
- 🛠 **كۈچلۈك ئارقا باشقۇرۇش بېتى (`admin.html`):** دەرس تەھرىرلەش، ئۆچۈرۈش، سۇئال-جاۋابلارغا چۈشەندۈرۈش بېرىش، ئىمتىھان نەتىجىلىرىنى كۆرۈش.
- 💬 **سۇئال-جاۋاب ۋە تەكلىپ-پىكىر:** باش بەتتىكى سۇئاللارنى باشقۇرۇش ۋە ئارقا بەتتىن بىۋاسىتە جاۋاب قايتۇرۇش.
- 🌙 **كېچە ۋە كۈندۈز ھالىتى (Dark/Light Mode):** كۆزنى ئاسرايدىغان تۈن نۇسخىسى تولۇق قوللاندى.
- ☁️ **Vercel & Supabase ماسلىشىشچانلىقى:** بۇلۇت مۇلازىمېتىرى ۋە PostgreSQL ساندانغا بىۋاسىتە ئۇلىنىدۇ.

## 📁 مۇندەرىجە قۇرۇلمىسى
```text
uyghur-tibb/
├── index.html           # ئاساسىي باش بەت ۋە ئوقۇغۇچى كۆرۈنمە يۈزى
├── admin.html           # ئارقا باشقۇرۇش سىستېمىسى
├── connect.html         # يەرلىك ساندان ۋە تور ئۇلاش سىنىقى
├── data.js              # ساندان ۋە دەرسلىك مەزمۇنلىرى
├── manifest.webmanifest # تېلېفونغا ئەپ قىلىپ قاچىلاش تەڭشىكى (PWA)
├── sw.js                # Service Worker
├── api/                 # Vercel Serverless مۇلازىمېتىر بۆلەكلىرى
│   ├── students.js
│   ├── submit_exam.js
│   └── ...
├── supabase_setup.sql   # Supabase PostgreSQL جەدۋەل قۇرۇش كودلىرى
└── vercel.json          # Vercel يوللاش تەڭشىكى
```
