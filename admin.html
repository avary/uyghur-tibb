⏳ كىرىش ئىجازىتى كۈتۈۋاتقان يېڭى ئوقۇغۇچىلار (Pending Approval)

ئوقۇغۇچىلار تىزىملاتقاندىن كېيىن، سىز «تەستىقلاش»نى باسسىڭىزلا دەرسلەر ئېچىلىدۇ.
ئوقۇغۇچى ئىسمى تېلېفون نومۇرى تىزىملاتقان ۋاقتى ھالىتى مەشغۇلات (تەستىقلاش)
ھازىرچە تەستىق كۈتۈۋاتقان يېڭى ئوقۇغۇچى يوق.

✅ ئىجازەت بېرىلگەن ئوقۇغۇچىلار (Approved)

ئوقۇغۇچى ئىسمى تېلېفون نومۇرى تىزىملاتقان ۋاقتى ھالىتى مەشغۇلات
تېخى تەستىقلانغان ئوقۇغۇچى يوق.

📝 تاپشۇرۇلغان ئىمتىھانلار ستاتىستىكىسى

ۋاقتى دائىرىسى سوئال سانى ئېرىشكەن نومۇرى نەتىجە
تېخى ئىمتىھان خاتىرىسى يوق.
💬 باش بەت سوئال-جاۋاب ۋە پىكىرلەرنى باشقۇرۇش

ئوقۇغۇچىلار ئەپنىڭ باش بېتىدىكى «💬 سوئال-پىكىر تاختىسى»دا قالدۇرغان سوئاللىرى بۇ يەردە كۆرۈنىدۇ. سىز قايتۇرغان جاۋاب دەرھال ئوقۇغۇچىغا ئالتۇن رەڭلىك «🌿 باشقۇرغۇچى جاۋابى» بولۇپ چىقىدۇ.

ئوقۇغۇچى ۋاقتى سوئال ياكى پىكىر قايتۇرۇلغان جاۋاب مەشغۇلات
تېخى سوئال ياكى پىكىر چۈشمىدى.
⚙️ سىستېما ۋە باشقۇرغۇچىلارنى باشقۇرۇش

👨‍💼 باشقۇرغۇچى ھېساباتلىرى (Admin Accounts)

سىستېمىغا ئوقۇتۇش مەسئۇللىرى ۋە باشقۇرغۇچىلارنى ئايرىم كىرىش ھېساباتى بىلەن قوشالايسىز.

كىرىش نامى (Username) باشقۇرغۇچى ئىسمى ھوقۇق دەرىجىسى مەشغۇلات

➕ يېڭى باشقۇرغۇچى قوشۇش

💾 سانلىق مەلۇمات زاپاسلاش ۋە ئەسلىگە كەلتۈرۈش

بارلىق كىرگۈزگەن دەرسلىكلىرىڭىز، سوئال ئامبىرى ۋە ئۇستازلارنى بىر كۇنۇپكا بىلەن كومپىيوتېرىڭىزغا چۈشۈرۈۋالالايسىز ياكى قايتا ئەكىرەلەيسىز.

⚡ Supabase بۇلۇت ساندانىنى ئۇلاش (PostgreSQL)

⏳ تەكشۈرۈلىۋاتىدۇ...

بۇلۇت ساندانى ئۇلانغاندىن كېيىن بارلىق تېلېفونلاردىن تىزىملاتقان ئوقۇغۇچىلار، تەستىقلار ۋە سوئال-جاۋابلار مەڭگۈلۈك كۈچلۈك PostgreSQL ساندىنىدا ساقلىنىدۇ.

💡 3 باسقۇچتا ئۇلاش قوللانمىسى:
1. supabase.com تورىغا كىرىپ ھەقسىز بىر تۈر (Project) قۇرۇڭ.
2. سول تەرەپتىكى «SQL Editor» غا يۇقىرىدىكى «جەدۋەل قۇرۇش SQL كودىنى كۆچۈرۈش» نى بېسىپ كۆچۈرۈۋالغان كودنى چاپلاپ «RUN» كۇنۇپكىسىنى بېسىڭ.
3. تۈر تەڭشىكىدىن (Project Settings ➡️ API) Project URL بىلەن anon public key نى كۆچۈرۈپ يۇقىرىغا چاپلاپ «ئۇلىنىشنى سىناش ۋە ساقلاش» نى بېسىڭ!
